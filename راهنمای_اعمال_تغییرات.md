### ۱) `apps/products/models.py`

**الف.** خط import بالای فایل:
```python
from django.db import models
```
را با این جایگزین کنید:
```python
from django.db import models, transaction
from .attribute_utils import adjust_usage_count
```

**ب.** در کلاس `ProductAttributeValue`، کل متد `save` فعلی را با این جایگزین کنید:
```python
    def save(self, *args, **kwargs):
        with transaction.atomic():
            old = None
            if self.pk:
                old = type(self).objects.filter(pk=self.pk).values("attribute_id", "value_text").first()
            super().save(*args, **kwargs)
            new = type(self).objects.filter(pk=self.pk).values("attribute_id", "value_text").first()

            def key(row):
                if not row:
                    return None
                text = " ".join((row["value_text"] or "").casefold().split())
                return (row["attribute_id"], text) if text else None

            old_key, new_key = key(old), key(new)
            if old_key != new_key:
                if old_key:
                    adjust_usage_count(old["attribute_id"], old["value_text"], -1)
                if new_key:
                    adjust_usage_count(new["attribute_id"], new["value_text"], +1)
```

### ۲) `apps/products/views.py`

**الف.** داخل کلاس `ProductFilterMixin` (مثلاً زیر `_build_filter_definitions`) این متد را اضافه کنید:
```python
    @staticmethod
    def _parse_decimal(raw):
        from decimal import Decimal, InvalidOperation
        if raw in (None, ""):
            return None
        try:
            value = Decimal(str(raw).strip())
        except InvalidOperation:
            return None
        return value if value.is_finite() else None
```

**ب.** در `apply_filters`، کل شاخه‌ی `elif template.filter_type == CategoryAttributeTemplate.FILTER_TYPE_RANGE:` (از همان `elif` تا `qs = qs.filter(Exists(spec_qs))`) را با این جایگزین کنید:
```python
                elif template.filter_type == CategoryAttributeTemplate.FILTER_TYPE_RANGE:
                    min_value = self._parse_decimal(request.GET.get(f"{param}_min"))
                    max_value = self._parse_decimal(request.GET.get(f"{param}_max"))
                    if min_value is not None or max_value is not None:
                        from django.db.models import Case, DecimalField, Value, When
                        from django.db.models.functions import Cast, Replace, Trim
                        numeric_pattern = r"^[0-9]{1,13}([.][0-9]{1,6})?$"
                        cleaned = Trim(Replace("value", Value(template.unit or ""), Value("")))
                        spec_qs = ProductSpecification.objects.filter(
                            product_id=OuterRef("pk"), key=template.name,
                        ).annotate(cleaned_value=cleaned).annotate(
                            numeric_value=Case(
                                When(cleaned_value__regex=numeric_pattern,
                                     then=Cast("cleaned_value", DecimalField(max_digits=20, decimal_places=6))),
                                default=None,
                                output_field=DecimalField(max_digits=20, decimal_places=6),
                            )
                        )
                        if min_value is not None:
                            spec_qs = spec_qs.filter(numeric_value__gte=min_value)
                        if max_value is not None:
                            spec_qs = spec_qs.filter(numeric_value__lte=max_value)
                        qs = qs.filter(Exists(spec_qs))
```
