# راهنمای اصلاحات دور دوازدهم

## ۱) چسباندن اسلایدر به منوی بالایی (بدون فاصله)

علت فاصله: `.hero-slider-section` یک `padding-top: 1.25rem` داشت.
**اصلاح:** در `static/css/header-hero-v2.css` این مقدار به `padding-top: 0`
تغییر کرد؛ الان اسلایدر دقیقاً زیر ردیف منو (دسته‌بندی کالاها و بقیه) می‌چسبد،
درست مثل تصویر ۰۰۱.

## ۲) دایره‌های سریع (قطر ۸۰ پیکسل) زیر اسلایدر

یک مدل جدید و یک فیلد جدید اضافه شد:

- مدل جدید `QuickCircle` (در `apps/core/models.py`): تصویر + عنوان زیر تصویر
  + لینک اختیاری + ترتیب + فعال/غیرفعال.
- فیلد جدید `quick_circles_heading` روی `SiteSetting`: همان «خط توضیحی بالای
  دایره‌ها» که خواستید؛ اگر خالی بماند، اصلاً نمایش داده نمی‌شود.

مدیریت کامل از داشبورد: **داشبورد → محتوای سایت → دایره‌های سریع** (افزودن/
ویرایش/حذف هر دایره) و متن بالای آن‌ها هم از **داشبورد → محتوای سایت →
تنظیمات سایت** قابل تغییر است.

نمایش: ردیف دایره‌ها بین اسلایدر و ۴ کادر تبلیغاتی قرار گرفت، هر دایره
۸۰×۸۰ پیکسل (تصویر به‌صورت خودکار گرد نمایش داده می‌شود، فرقی نمی‌کند
تصویر آپلودی‌تان مربعی باشد یا نه) با یک برچسب متن زیرش.

## ۳) مگامنوی دسته‌بندی کالاها -- یک نکته‌ی مهم قبل از توضیح فنی

تصویر ۰۰۲ (دیجی‌کالا) یک مگامنوی **چند ستونه با عنوان مجزا برای هر ستون**
است: مثلاً زیر «لپ‌تاپ» چهار ستون جدا با عنوان‌های «انتخاب لپ‌تاپ»،
«لپ‌تاپ گیمینگ»، «قیمت لپ‌تاپ» و «براساس کاربری» وجود دارد که هرکدام یک
گروه‌بندی کاملاً دستی و متفاوت از ساختار دسته‌بندی محصول است (مثلاً «قیمت
لپ‌تاپ» اصلاً یک دسته‌بندی نیست، بلکه یک فیلتر قیمتی است).

ساختار دیتابیس فعلی شما (`ProductCategory` با `parent`/`children`) فقط
یک درخت ساده‌ی والد/فرزند است و از پیاده‌سازی «چند ستون با عنوان دلخواه
و دلخواه» (که نیازمند مدلی تازه مثل «گروه منو» + «آیتم‌های هر گروه» است)
پشتیبانی نمی‌کند. ساختن آن ساختار کاملاً جدید، یک فاز طراحی و پیاده‌سازی
جداگانه است (مدل جدید + پنل مدیریت جدید + تغییر View/Context processor).

**در همین دور چه کاری انجام شد:** به‌جای آن ساختار پیچیده، مگامنوی فعلی
(که هر دسته‌ی سطح‌بالا را با هاور/کلیک باز می‌کند) را از یک لیست باریک
تک‌ستونه، به یک **پنل چندستونه‌ی خودکار** (شبیه روزنامه، بدون عنوان مجزا
برای هر ستون) تبدیل کردم که همه‌ی زیرمجموعه‌های همان دسته را بر اساس تعداد
آیتم، خودکار در ۲ یا ۳ ستون می‌چیند. این دقیقاً شبیه بخش راست تصویر ۰۰۲
(ستون باریک دسته‌های اصلی) + یک پنل عریض‌تر در کنارش است، ولی بدون
گروه‌بندی عنوان‌دار داخلی.

اگر گروه‌بندی عنوان‌دار (دقیقاً مثل تصویر ۰۰۲) را هم می‌خواهید، به من
بگویید تا به‌عنوان یک فاز جداگانه (مدل `MenuColumnGroup` + پنل مدیریت آن)
پیاده‌سازی کنم.

### فایل تغییریافته برای این بخش
فقط CSS (`static/css/header-hero-v2.css`، بخش `.categories-submenu`)
تغییر کرد؛ هیچ تغییری در HTML/View لازم نبود چون داده‌ی زیرمجموعه‌ها
(`cat.children.all`) از دور سوم همین پروژه از قبل در دسترس بود.

| `apps/dashboard/views.py` | طبق `views_ADDITION.py`: import به‌روزرسانی شود، یک فیلد به `DashboardSiteSettingUpdateView` اضافه شود، و ۴ ویوی جدید به انتها اضافه شود |
| `apps/dashboard/urls.py` | طبق `urls_ADDITION.py`: ۴ مسیر جدید به انتهای `urlpatterns` اضافه شود |

## بعد از اعمال تغییرات

```bash
python manage.py migrate
```
(یا اگر خودتان دستی ویرایش کردید: `python manage.py makemigrations core` و
بعد `migrate`)

## تست پیشنهادی
۱. صفحه اصلی را باز کنید -- اسلایدر باید بدون هیچ فاصله‌ای به منوی بالا
   چسبیده باشد.
۲. از داشبورد چند «دایره سریع» اضافه کنید و یک متن برای «عنوان بالای
   دایره‌های سریع» در تنظیمات سایت بگذارید -- باید بین اسلایدر و کادرهای
   تبلیغاتی ظاهر شوند.
۳. روی «دسته‌بندی کالاها» کلیک کنید و موس را روی دسته‌ای ببرید که چند
   زیرمجموعه دارد -- باید یک پنل عریض و چندستونه باز شود، نه یک لیست باریک.
