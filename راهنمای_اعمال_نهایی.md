## ویرایش ۱ -- `apps/products/views.py`
بالای فایل، کنار importهای دیگر اضافه کنید:
```python
from .spec_utils import build_comparison_rows
```
کل کلاس `CompareView` را با این جایگزین کنید:
```python
class CompareView(ListView):
    template_name = "products/compare.html"
    context_object_name = "products"

    def get_queryset(self):
        ids = self.request.session.get(COMPARE_SESSION_KEY, [])
        return (
            Product.objects.filter(pk__in=ids, status="published")
            .select_related("brand")
            .prefetch_related(
                "specifications",
                "attribute_values__attribute",
                "attribute_values__selected_values",
            )
        )

    def get_context_data(self, **kwargs):
        ctx = super().get_context_data(**kwargs)
        products = list(ctx["products"])
        rows = build_comparison_rows(products)
        ctx["products"] = products
        ctx["comparison_rows"] = rows
        ctx["spec_keys"] = [row["key"] for row in rows]
        return ctx
```

## ویرایش ۲ -- `apps/products/models.py` (قانون تنوع، بند ۵)
در `ProductAttributeValue.clean()` این خط‌ها را (که قبلاً از راهنمای اول اضافه کرده‌اید):
```python
        if self.variant_id and self.product_id and self.variant.product_id != self.product_id:
            raise ValidationError({"variant": "این تنوع متعلق به همین محصول نیست."})
```
با این جایگزین کنید:
```python
        if self.variant_id:
            raise ValidationError({"variant": "مشخصات مخصوص تنوع باید در «مشخصات تنوع» (VariantAttributeValue) ثبت شود."})
```
(داده‌ی فعلی شما ۰ رکورد با variant دارد، پس چیزی نمی‌شکند.)

## ویرایش ۳ -- `apps/products/admin.py` (جلوگیری از سردرگمی دو مسیر)
در `ProductSpecificationInline` دو خط اضافه کنید:
```python
    verbose_name = "مشخصه فنی (ساختار قدیمی؛ مبنای فیلتر دسته‌بندی)"
    verbose_name_plural = "مشخصات فنی (ساختار قدیمی؛ مبنای فیلتر دسته‌بندی)"
```
در `ProductAttributeValueInline` دو خط اضافه کنید و `"variant"` را از `fields` حذف کنید:
```python
    verbose_name = "مشخصه پویا (ساختار جدید؛ نمایش و مقایسه)"
    verbose_name_plural = "مشخصات پویا (ساختار جدید؛ نمایش و مقایسه)"
    fields = ("attribute", "value_text", "value_number", "value_boolean", "value_date", "value_file")
```
